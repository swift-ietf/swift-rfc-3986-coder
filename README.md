# swift-rfc-3986-coder

Wire coders for the RFC 3986 URI domain model in [swift-rfc-3986](https://github.com/swift-ietf/swift-rfc-3986): `RFC_3986.URI.Coder` and the nested `Scheme.Coder`, `Userinfo.Coder`, `Host.Coder`, `Port.Coder`, `Path.Coder`, `Query.Coder`, `Fragment.Coder` and `Authority.Coder` parse and serialize each component's text form over any byte cursor, `RFC_3986.PercentEncoded.Coder` codes a single percent-encoded octet, `Coder.Codable` gives every component `encoded()` and `init(decoding:)`, and the `ASCII.Parseable`, `ASCII.Serializable` and `Binary.Serializable` conformances live here so that the domain package stays a pure model. `RFC_3986.URI.Host` serializes an IPv6 literal in its RFC 5952 canonical form. The package also carries the composing initializer `RFC_3986.URI.init(scheme:authority:path:query:fragment:)`, which renders its authority through the serializer, and the `RFC 3986 Coder Foundation Integration` product adds the `Codable` conformances of `URI.Host` and `URI.Authority`, encoding through the serializer and decoding through the domain's validating initializers.
